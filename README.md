# wordle

终端 Wordle 小游戏：6 次机会猜一个 5 字母英文单词。纯标准库，离线可玩。

## 玩法

```bash
cd ~/workspace/ai-forks/wordle
python3 -m wordle
```

每轮输入一个 5 字母英文单词（必须在内置词库中），回车后看反馈：

- 🟩 字母和位置都对
- 🟨 字母在单词里，但位置不对
- ⬛ 字母不在单词里

下方还有 QWERTY 键盘提示：绿色=已确定，黄色=在词中但位置未定，灰色=已排除。

## 参数

| 参数 | 说明 |
|---|---|
| `--word CRANE` | 固定答案（测试/演示用） |
| `--daily` | 每日一词：按日期确定答案，同一天玩到的是同一个词 |
| `--auto [g1,g2]` | 自动演示：按逗号分隔的猜测序列自动玩一局；不带参数时用内置演示序列 |
| `-h` | 帮助 |

退出码：`0` 猜中，`1` 失败，`2` 参数错误。

## 评分规则（重复字母）

实现的是标准 Wordle 规则：**先标绿，再按剩余字母数标黄**。

举例：答案 `REESE`，猜 `EERIE` → `🟨🟩🟨⬛🟩`：

1. 先标绿：第 2、5 个 E 位置正确 → 🟩
2. 答案剩余字母：R、E、S；猜测剩余：E、R、I
3. 从左到右：第 1 个 E 还有剩余 → 🟨；R 有剩余 → 🟨；I 没有了 → ⬛

## 已知局限

- 内置 200 个常见 5 字母词，词库是人工精选快照，不是完整词典
- 只认词库里的词；拼写正确但冷僻的词会被拒绝
- 键盘提示用 ANSI 颜色，不支持 ANSI 的终端里颜色不显示，但 🟩🟨⬛ 反馈不受影响
- 中文说明，游戏单词是英文（Wordle 本来如此）
